Frequently asked questions

Is this ID card crop and print tool free?

Yes. Aadhaar, PAN, Voter ID, Ayushman Card, ABHA, APAAR, UDID, e-Shram, Kisan Card and any other ID card tool on this site is completely free with no sign-up.

Is my Aadhaar or PAN PDF uploaded to a server?

No. The PDF or image is opened and rendered entirely inside your own browser using PDF.js and canvas processing. Nothing is sent to or stored on any server.

What is the difference between 4x6 and A4 output?

4x6 photo paper output is a 1200x1800 pixel portrait layout meant for PVC card printing. A4 output is a 3508x2480 pixel landscape layout meant for printing multiple cards on a standard office printer.

My e-Aadhaar PDF is password protected. Can I still use this tool?

Yes — enter the PDF's password in the password field before processing. Your password is used only inside your browser to open the file locally.

What if my ID does not match Aadhaar, PAN, Voter ID or Ayushman layouts?

Use the "Any Other ID" option — upload the front side (and optionally the back side separately) as a PDF or photo, and both sides will be arranged neatly for a perfect 4x6/A4 print, no matter which document it is.
